# 🎮 Makler PS5 Sniper

Каждые 20 минут проверяет объявления «Игровые приставки» на makler.md по городам ПМР, находит PS5 (Fat / Slim / Pro, с дисководом) и присылает в Telegram:

- 🆕 **новое объявление**: фото, название, цена, город, описание, дисковод, ссылка;
- 🔥 **ВЫГОДНО**: цена ≤ $650;
- 📉 **цена снижена**: старая и новая цена;
- ⚠️ **сайт недоступен**: после 3 неудачных проверок подряд, а потом ✅ когда доступ восстановится.

Если ничего не изменилось, бот молчит. Поднятые старые объявления повторно не присылаются.

## Почему проверка идёт с компьютера, а не из облака

Makler.md стоит за Cloudflare и отвечает **403** на запросы из дата-центров. Это проверено на GitHub Actions, а с домашнего интернета сайт открывается нормально. Поэтому проверки запускает **Планировщик задач Windows** на вашем ПК. Результаты (`data/`) после каждой проверки отправляются в GitHub, откуда их читает виджет на iPhone.

- Если ПК выключен или спит, проверки не идут. Пропущенная проверка запускается сразу после включения ПК.
- Виджет показывает время последней успешной проверки и становится жёлтым, если данные старше 3 часов.

```
Планировщик Windows (каждые 20 мин)
   └─ windows\run.ps1
        ├─ git pull
        ├─ python -m sniper.main
        │    ├─ обходит страницы категории (пауза 2 с)
        │    ├─ отбирает PS5 (sniper/classify.py)
        │    ├─ сравнивает с data/state.json → новые / снижения
        │    └─ Telegram
        └─ git push data/  →  iPhone-виджет читает data/widget.json
```

### Что отбирается
- Источник: категория с вашим фильтром городов (`config.json → category_url`). Страница поиска `/an/search` не используется, потому что robots.txt её запрещает.
- Объявление определяется по ID, поэтому поднятие на Makler не считается новым объявлением.
- Если дисковод не указан, объявление всё равно приходит с пометкой «❓ Дисковод: не указан». Явные Digital и «без дисковода» отсеиваются.
- Отсеиваются подписки, аккаунты, игры, диски, геймпады, аренда, «куплю/скупаю», «обмен на PS5», ремонт, VR, PS Portal, другие консоли и всё дешевле $150. Консоль в комплекте с играми и аксессуарами остаётся.
- Магазинные объявления «PS5/PS4 от …» приходят, но их цена не учитывается в «выгодно» и минимальной цене.
- Если сайт недоступен, данные не меняются. Если не отправилось сообщение в Telegram, оно уйдёт при следующей проверке.

## Настройка

### 1. Telegram-бот
1. **@BotFather** → `/newbot`. Сохраните **токен**.
2. Откройте своего бота и нажмите **Start**.
3. **@userinfobot** пришлёт ваш **chat id**.

### 2. Запуск на ПК (один раз)
В PowerShell из папки проекта:
```powershell
powershell -ExecutionPolicy Bypass -File windows\setup.ps1
```
Скрипт спросит токен и chat id и сохранит их в `.env`. Этот файл есть только на вашем ПК и в git не попадает. Затем он установит зависимости, пришлёт в Telegram «✅ Telegram подключён» и создаст в Планировщике две задачи: **PS5 Sniper** (проверка каждые 20 минут) и **PS5 Sniper Commands** (раз в минуту ждёт команду /check от бота; чужие чаты игнорируются). Через минуту придёт сводка «PS5 Sniper запущен» с текущими подходящими объявлениями.

### 3. Виджет на iPhone
1. Установите бесплатное приложение **Scriptable** из App Store.
2. В Scriptable нажмите **+** и вставьте содержимое `widget/ps5_sniper_widget.js` (ссылка на данные уже прописана).
3. Назовите скрипт `PS5 Sniper` и запустите ▶️ для проверки.
4. На рабочем столе: долгое нажатие → **+** → Scriptable → размер (Small / Medium / Large) → **Edit Widget** → Script: `PS5 Sniper`.

На виджете видны минимальная цена с моделью и городом, лучшие объявления (🔥 выгодные сверху, 💿/❓ дисковод, NEW), число новых за сутки, время последней проверки и состояние (● зелёный: работает, жёлтый: сбой или нет свежих данных, красный: сайт недоступен). Нажатие открывает объявление.

> iOS сама решает, когда обновлять виджеты, обычно раз в 15–60 минут. О новых объявлениях надёжно сообщает Telegram.

## Управление

| Что нужно | Как |
|---|---|
| Проверить сейчас | написать боту **/check** (или «проверь»). Через минуту придёт отчёт. С ПК: `Start-ScheduledTask -TaskName "PS5 Sniper"` |
| Посмотреть лог | `logs\run.log` |
| Изменить интервал | `powershell -ExecutionPolicy Bypass -File windows\setup.ps1 -IntervalMinutes 60` (по умолчанию 20) |
| Порог «выгодно» | `config.json → deal_usd` (сейчас 650) |
| Курсы валют | `config.json → rates_per_usd`: сколько руб/лей/евро за $1. Дробные числа только через **точку**: `18.43`, не `18,43` |
| Другие города | замените `category_url` в `config.json` ссылкой из адресной строки после выбора фильтров на makler.md |
| Сменить токен/chat id | удалите `.env` и снова запустите `windows\setup.ps1` |
| **Остановить после покупки** | `Get-ScheduledTask -TaskName "PS5 Sniper*" \| Unregister-ScheduledTask -Confirm:$false` |

## Ограничения
- Проверки идут, только пока ПК включён и не спит.
- Если Makler поменяет вёрстку, бот пришлёт «⚠️ недоступен». Тогда нужно поправить `sniper/parse.py`.
- Секреты, которые вы добавили в GitHub Secrets, больше не используются, их можно удалить.

## Разработка

```powershell
pip install -r requirements.txt pytest
python -m pytest -q
```

Структура: `sniper/parse.py` (HTML), `sniper/classify.py` (что считается PS5), `sniper/money.py` (валюты), `sniper/notify.py` (Telegram), `sniper/main.py` (проход и состояние), `windows/` (Планировщик), `widget/` (Scriptable).
