# 🎮 Makler PS5 Sniper

Каждый час проверяет объявления «Игровые приставки» на makler.md по городам ПМР, находит PS5 (Fat / Slim / Pro, с дисководом) и присылает в Telegram:

- 🆕 **новое объявление**: фото, название, цена, город, описание, дисковод, ссылка;
- 🔥 **ВЫГОДНО**: если цена ≤ $650;
- 📉 **цена снижена**: старая и новая цена;
- ⚠️ **сайт недоступен**: после 3 неудачных проверок подряд, а потом ✅ когда доступ восстановится.

Если ничего не изменилось, бот молчит. Поднятые старые объявления повторно не присылаются.
Всё работает на бесплатном GitHub Actions, компьютер может быть выключен.

## Как это устроено

```
GitHub Actions (cron раз в час)
   └─ python -m sniper.main
        ├─ обходит все страницы категории (с паузой 2 с)
        ├─ отбирает PS5 (sniper/classify.py)
        ├─ сравнивает с data/state.json → новые / снижения цены
        ├─ шлёт Telegram
        └─ сохраняет data/state.json и data/widget.json → коммит в репозиторий
iPhone: Scriptable читает data/widget.json по raw-ссылке
```

- Источник: категория с вашим фильтром городов (`config.json → category_url`). Страница поиска `/an/search` не используется, потому что robots.txt её запрещает.
- Объявление определяется по ID, поэтому поднятие на Makler не считается новым объявлением.
- Если дисковод не указан, объявление всё равно приходит с пометкой «❓ Дисковод: не указан». Явные Digital и «без дисковода» отсеиваются.
- Отсеиваются подписки, аккаунты, игры, диски, геймпады, аренда, «куплю/скупаю», «обмен на PS5», ремонт, VR, PS Portal и другие консоли. Консоль в комплекте с играми и аксессуарами остаётся.
- Если сайт недоступен, данные не меняются. Если не отправилось сообщение в Telegram, оно уйдёт при следующей проверке.

## Настройка (≈10 минут)

### 1. Telegram-бот

1. В Telegram откройте **@BotFather**, отправьте `/newbot`, придумайте имя. Получите **токен** вида `123456:ABC...`.
2. Откройте своего нового бота и нажмите **Start**. Без этого бот не сможет вам писать.
3. Узнайте свой **chat id**: напишите боту **@userinfobot**, он ответит числом `Id: 123456789`.

### 2. Репозиторий на GitHub

1. Создайте на github.com **публичный** репозиторий, например `ps5-sniper`, без README.
2. Загрузите проект. В PowerShell из папки проекта:
   ```powershell
   git remote add origin https://github.com/<ВАШ_ЛОГИН>/ps5-sniper.git
   git push -u origin main
   ```
3. Откройте **Settings → Secrets and variables → Actions → New repository secret** и создайте два секрета:
   - `TELEGRAM_BOT_TOKEN`: токен от BotFather;
   - `TELEGRAM_CHAT_ID`: ваш chat id.
4. Откройте **Settings → Actions → General → Workflow permissions** и выберите **Read and write permissions**, затем Save.
5. Откройте вкладку **Actions → PS5 Sniper → Run workflow**. Через минуту придёт сообщение «PS5 Sniper запущен» со списком текущих подходящих объявлений.

Дальше всё работает само. Секреты хранятся только в GitHub Secrets, в коде их нет.

### 3. Виджет на iPhone

1. Установите бесплатное приложение **Scriptable** из App Store.
2. В Scriptable нажмите **+** и вставьте содержимое `widget/ps5_sniper_widget.js`.
3. В строке `DATA_URL` подставьте свою ссылку:
   `https://raw.githubusercontent.com/<ВАШ_ЛОГИН>/ps5-sniper/main/data/widget.json`
4. Назовите скрипт `PS5 Sniper` и запустите ▶️ для проверки.
5. На рабочем столе: долгое нажатие → **+** → Scriptable → выберите размер (Small / Medium / Large) → **Edit Widget** → Script: `PS5 Sniper`. Нажатие на виджет сразу открывает объявление (или категорию), «When Interacting» можно не трогать.

На виджете видны минимальная цена с моделью и городом, лучшие объявления (🔥 выгодные сверху, 💿/❓ дисковод, NEW), число новых за сутки, время последней проверки и состояние системы (● зелёный: работает, жёлтый: сбой или давно не обновлялось, красный: сайт недоступен). Нажатие на строку открывает объявление.

> iOS сама решает, когда обновлять виджеты: обычно раз в 15–60 минут, иногда реже. Поэтому виджет нужен для обзора, а о новых объявлениях надёжно сообщает Telegram.

## Управление

| Что нужно | Как |
|---|---|
| Изменить интервал | `.github/workflows/monitor.yml`, строка `cron`: `"*/30 * * * *"` каждые 30 мин, `"17 */2 * * *"` каждые 2 часа |
| Порог «выгодно» | `config.json → deal_usd` (сейчас 650) |
| Курсы валют | `config.json → rates_per_usd`: сколько руб/лей/евро за $1 |
| Другие города | замените `category_url` в `config.json` ссылкой из адресной строки после выбора фильтров на makler.md |
| Проверить сейчас | Actions → PS5 Sniper → Run workflow |
| **Остановить после покупки** | Actions → PS5 Sniper → «⋯» → **Disable workflow** (или удалить репозиторий) |

Изменения в `config.json` и `monitor.yml` можно вносить прямо на github.com (иконка карандаша).

## Ограничения

- GitHub запускает расписание с опозданием до 5–20 минут, иногда пропускает запуск при высокой нагрузке.
- Если в публичном репозитории 60 дней не было коммитов, GitHub отключает расписание. Здесь бот коммитит данные каждый час, так что этого не случится.
- Если Makler поменяет вёрстку, проверка начнёт падать, и бот пришлёт «⚠️ недоступен». Тогда нужно поправить `sniper/parse.py`.
- Магазинные объявления «PS5/PS4 от …» приходят, но их цена не учитывается в «выгодно» и минимальной цене, потому что она относится к нескольким консолям.

## Разработка

```powershell
pip install -r requirements.txt pytest
python -m pytest -q
```

Структура: `sniper/parse.py` (HTML), `sniper/classify.py` (что считается PS5), `sniper/money.py` (валюты), `sniper/notify.py` (Telegram), `sniper/main.py` (проход и состояние), `widget/` (Scriptable).
