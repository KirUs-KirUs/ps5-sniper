# Makler PS5 Sniper — дизайн

## Зачем
Личный временный мониторинг объявлений PS5 на makler.md (ПМР: Тирасполь, Бендеры и др.),
чтобы купить консоль, не проверяя сайт вручную. Работает в облаке без ПК.

## Цели
- Раз в час (настраиваемо) проверять категорию «Игровые приставки» с фильтром городов.
- Находить физические PS5 (Fat/Slim/Pro, новые и б/у) с дисководом; если дисковод неясен — оставлять с пометкой.
- Telegram: новое объявление (фото, заголовок, цена, город, описание, дисковод, ссылка); ≤ $650 — выделено «🔥 ВЫГОДНО»;
  снижение цены — отдельное сообщение «было → стало». Молчать, если ничего не изменилось.
- Поднятие старого объявления не порождает уведомление (ключ — ID объявления).
- Виджет iPhone (Scriptable): лучшие объявления, мин. цена, модель+город, кол-во новых, время последней проверки, статус.

## Не цели / анти-цели
- Без БД, серверов, платных сервисов, браузерной автоматизации.
- Не использовать `/an/search` (запрещён robots.txt).
- Не спамить: первый запуск — одна сводка, а не десятки сообщений.

## Подходы
1. **GitHub Actions cron + Python + state.json в репозитории** — выбран. Бесплатно, ноль обслуживания,
   история в git, легко остановить (Disable workflow). Минус: cron может опаздывать на 5–20 мин.
2. Cloudflare Worker + KV — точный cron, но JS-парсинг HTML и больше настройки.
3. Бесплатный VPS — избыточное обслуживание.
Репозиторий публичный (выбор пользователя): виджет читает `data/widget.json` по raw-ссылке, секреты — в GitHub Secrets.

## Устройство
- `sniper/fetch.py` — HTTP с ретраями, пауза 2 с между страницами, обход страниц категории до пустой (макс. 25).
- `sniper/parse.py` — разбор списка (`article#tr_an-<id>`: заголовок, цена+валюта, город, текст, миниатюра)
  и карточки (og:description, og:image).
- `sniper/classify.py` — PS5 или нет, модель (Fat/Slim/Pro/?), статус дисковода (yes/no/unknown), исключения
  (подписки, игры, аккаунты, геймпады, аренда, куплю/скупаю, обмен на PS5, ремонт/прошивка как услуга, другие консоли).
- `sniper/money.py` — пересчёт в USD по курсам из `config.json`.
- `sniper/notify.py` — Telegram sendPhoto/sendMessage (HTML), фоллбэк на текст, если фото не прошло.
- `sniper/main.py` — оркестрация: загрузить state → обойти → классифицировать → диффы → уведомить → сохранить
  state и widget.json. При недоступности сайта state не трогается, счётчик ошибок растёт; после 3 подряд неудач
  одно сообщение «сайт недоступен», затем «восстановлено».
- Состояние `data/state.json`: listings{id: title, price, currency, usd, city, model, disc, first_seen, last_seen, notified,
  price_history}, health{last_ok, last_run, consecutive_failures}. Запись атомарная (tmp+rename), коммит из workflow.
- Объявление считается снятым, если не видно 7 дней — удаляется из виджета (остаётся в state ещё 30 дней).
- Workflow: `schedule: cron "17 * * * *"` + `workflow_dispatch`, concurrency group, коммит data/ при изменениях.

## Решения исполнителя (мои)
- Digital без упоминания дисковода/привода в комплекте — исключать; «Digital + дисковод» — включать.
- Pro: дисковод только если упомянут; иначе unknown (с пометкой), явное «без дисковода» — исключать.
- Курсы по умолчанию: USD=1, EUR=1.08, MDL=17.5, руб (ПМР)=16.3 за $1 — правятся в config.json.
- Первый запуск: тихая запись + одна сводка с топом подходящих.
